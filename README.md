# Developer Portfolio

## Project Preview

![Portfolio Screenshot](./Screenshot.png)

## Description

This project is a **Modern Developer Portfolio Website** built using **React.js, Tailwind CSS, and Framer Motion**.

It showcases projects, skills, and experience through a visually immersive and interactive UI. The portfolio focuses on delivering a **premium user experience** using smooth animations, custom cursor interactions, and a clean glassmorphism design.

The project follows a **component-based architecture**, making it scalable and easy to maintain. It is ideal for developers who want to build a professional and modern personal portfolio.

---

## Features

* Modern and minimal UI design
* Built using **React.js with Vite**
* Styled with **Tailwind CSS**
* Smooth animations using **Framer Motion**
* Custom animated cursor
* Interactive UI (hover effects, tilt, magnetic interactions)
* Fully responsive design
* Light & Dark mode support
* Component-based architecture

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/yourusername/portfolio.git
```

### 2. Install dependencies

```
npm install
```

### 3. Run the project

```
npm run dev
```

The application should now be running locally.
